## 安全约束与架构取舍

内存事务队列只保证同一个 Node.js 进程内的开发行为，不代表分布式或 MySQL 并发已验证。事务回调处理的是内存聚合；MySQL 接入需要重新实现事务查询/写入边界，不能将全表加载成 Map 作为生产存储实现。

报价有效期默认 5 分钟，未支付期限默认 15 分钟，是待评审的开发参数，不是用户协议或已批准的取消政策。示例定价仅为测试数据。真实部署前应将已批准的参数集中配置并纳入规则快照。

取消/超时释放只允许 `paymentChannelSubmitted=false` 的订单；接入支付时必须先持久化支付尝试/提交事实，再调用外部渠道。进程崩溃或渠道结果未知时要保守处理，不能将状态复位为未提交并直接释放名额。不能因为没有收到成功回调就认定没有扣款。

开发 Bearer token 固定映射到一个本地用户，不能用它实现多租户或微信登录。示例资料默认关闭；只有本地环境允许启用。内存数据无审计持久性，不能用于真实地址、入户密码或任何生产资金记录。
