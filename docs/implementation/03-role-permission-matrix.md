## 实施要求

1. 接口服务端统一鉴权，按资源查询约束主体 ID；禁止先按任意 ID 查询后只检查登录。
2. 喂养师订单查询必须关联当前有效 assignment；凭证读取另校验履约时间窗和订单状态。
3. 后台权限采用 RBAC + 片区/工单/金额等数据范围；高风险读取、导出、退款和角色变更记录目的、操作者、时间和结果。
4. 退款申请人与审批人分离；超限操作需第二审批人。管理员不应自动拥有所有业务数据明文权限。
5. 访问凭证、手机号、证件号、精确地址不写入普通应用日志、错误消息或分析事件；展示脱敏，读取明文走专用审计路径。
6. 权限测试至少覆盖匿名、越权 ID、跨用户、跨喂养师、错误状态、授权过期、离职/封禁账号及后台数据范围。
7. 私有存储签名 URL 在到期前通常仍可使用，不能宣称改派后已签发链接立刻失效。要求立即撤销的入户凭证/精确地址应经过每次鉴权的服务端接口，禁止 CDN/客户端持久缓存；影像使用短时签名并明确剩余有效期，敏感争议影像可改走鉴权代理。对已经读取或截屏的数据不能承诺技术上可撤回。
