## 首轮研发顺序建议

1. 确认仓库和实际技术栈，建立开发配置、CI、数据库迁移及测试基础。
2. 完成服务目录、报价、预约占位与建单纵向切片；验证幂等、最后一个名额并发及事务回滚。
3. 接入微信登录及资源归属权限，再联调支付通知、主动查单、关单和退款补偿。测试替身必须显式标记且不能在生产启用。
4. 实现人工派单、接单、签到签退、私有影像及入户信息授权，并验证改派后的权限回收。
5. 实现售后、结算记录、对账、审计、告警和恢复演练；取得业务、财务、运营及合规核验后再灰度。

上述顺序是研发建议，不代表已承诺排期；负责人、营业主体、服务区域、价格、取消政策、数据保留期限等仍待确认。
